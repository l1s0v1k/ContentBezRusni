# BezRusni YTM

Автоматизований скрипт для Windows, який відстежує поточний трек у системі (наприклад, у веб-плеєрі або застосунку YouTube Music) та **автоматично пропускає російськомовний контент або треки російських виконавців**.

## Основні функції

- **Глобальне управління медіа (Windows):** Скрипт отримує дані про поточний трек напряму з ОС, тому працює з будь-яким плеєром, який підтримує системний контроль мультимедіа (YouTube Music, Spotify, сучасні веб-браузери).
- **Багаторівнева перевірка контенту:**
  - **Унікальні літери:** Миттєво реагує на специфічні російські літери (`ё`, `ы`, `э`, `ъ`).
  - **Словник точних слів:** Містить вбудовану базу виключно російських коротких слів та закінчень, щоб надійно відрізняти російську від української.
  - **Евристика:** Ймовірнісний аналіз тексту за допомогою бібліотеки `langdetect`.
- **API Перевірка артистів:** Для розпізнавання країни походження виконавців використовуються точні запити до **Deezer API**, **Wikidata** та **MusicBrainz**. Скрипт коректно розпізнає іноземних виконавців (США, Європа) та українських артистів.
- **Списки виключень:** 
  - `whitelist.txt` — локальний "білий список" довірених артистів.
  - `global_blacklist.txt` — глобальний чорний список російських виконавців (автоматично оновлюється через GitHub).

## Як це працює

Скрипт у фоні постійно моніторить поточний трек. Щойно пісня змінюється, скрипт аналізує назву та ім'я автора, вираховуючи `Score` (бал "російськості"). Якщо бал перевищує ліміт (65+), скрипт негайно відправляє системну команду `Next` (перемкнути на наступний трек), пропускаючи ворожий контент ще до того, як він почне грати.

## Встановлення та запуск

1. Переконайтеся, що у вас встановлено Python 3.9 або новіший.
2. Склонуйте репозиторій або завантажте файли.
3. Встановіть необхідні залежності:
   ```bash
   pip install requests langdetect transliterate winrt
   ```
4. У директорії зі скриптом створіть файл `whitelist.txt` (якщо його немає) та додайте туди своїх довірених виконавців (кожного з нового рядка), щоб уникнути хибних спрацьовувань.
5. Запустіть програму:
   ```bash
   python BezRusni_Global.py
   ```
